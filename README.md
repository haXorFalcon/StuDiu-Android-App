## 🚀 Installation

### Option 1 — Download APK (Recommended)

1. Go to the [**Releases**](https://github.com/haXorFalcon/StuDiu-Android-App/releases) tab
2. Download the latest **StuDiu v1** APK
3. Enable **"Install from unknown sources"** on your Android device
4. Install and enjoy 🎉

> ⚠️ Minimum Android version: **Android 6.0 (Marshmallow)**

---

### Option 2 — Build from Source

```bash
# Clone the repository
git clone https://github.com/haXorFalcon/StuDiu-Android-App.git

# Navigate to project directory
cd StuDiu-Android-App

# Install dependencies
npm install

# Run on Android
npx react-native run-android
```

> Make sure you have **Node.js**, **Android Studio**, and **React Native CLI** set up before building.

## 🎯 Who Is This For?

StuDIU is built specifically for **hostel students of Daffodil International University (DIU)** who struggle to:

- 📌 Track shared hostel expenses month to month
- 📌 Keep a record of personal daily spending
- 📌 Split utility bills, food costs, and rent with roommates
- 📌 Understand where their money goes
